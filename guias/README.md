# Guías semanales

Cada semana se sube aquí la guía con lo que se va a hacer esa semana: tareas, quién las hace y cómo hacerlas.

## Nombre del archivo

`semana-AAAA-MM-DD.md`, con la fecha del **lunes** de esa semana. Por ejemplo, `semana-2026-10-19.md`.

Así se ordenan solas por fecha.

## Qué debe tener cada guía

- **Reparto:** tabla con la tarea, la persona y el issue de GitHub
- **Cómo hacer cada tarea:** archivos, pasos y test
- **Dependencias:** qué tiene que estar hecho antes
